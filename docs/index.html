Three Frictionless Workflows

Designed to fit naturally into everyday dev routines.

⚡

Instant Post-Mortem

Run right after a crash. Inspects git state, packages, runtimes, and open ports in under 2 seconds.

npx crashpack
🎯

Command Wrapper

Streams output live. If your command passes (exit 0), nothing is printed. On non-zero exit, captures error logs + full context.

crashpack --wrap "npm test"
🔗

GitHub Issue Link

Pass --issue to generate a one-click GitHub issue creation URL preloaded with the redacted diagnostic markdown.

crashpack --issue
🛡️ Zero Secrets Leaked · Local Only

Mandatory Pass-Through Redaction

Redaction is not an afterthought. Built with TypeScript branded types so unredacted raw collector text cannot physically reach output sinks.

🔑 Comprehensive Token Patterns

Masks AWS, Stripe, GitHub PATs, JWTs, and private keys automatically based on Gitleaks pattern sets.

🗄️ Database URI Sanitization

Detects database connection strings and strips passwords (postgres://user:[redacted]@host).

🔒 Environment Variables

Lists variable names only. Values are parsed in memory to extract key names and are never written to the report, stored, or output.

🚫 Zero Network Calls

No telemetry, no tracking, and no cloud uploads. 100% offline-ready. Port detection opens loopback connections to 127.0.0.1 only.
